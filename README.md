#  Bicycles API

REST API developed as part of a **Vocational Training project**.

## Technologies

* Typescript
* Node.js
* Express
* Sequelize
* SQL

## Description

This API allows users to manage bicycle data through CRUD operations:

* **GET** — Retrieve bicycles
* **POST** — Create a bicycle
* **PUT** — Update a bicycle
* **DELETE** — Delete a bicycle

## Installation

```bash
npm install
```

Start the server with:

```bash
npm start
```

The API runs locally on `http://localhost:3000`.
